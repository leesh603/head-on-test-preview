## 플리거주크

- 호스트가 계산한 보스 체력에 추가 1.5배를 곱하지 않는다. 객차 피해는 전체 게이지에 한 번만 반영하며, 모든 객차를 파괴해도 기관차의 마지막 30%가 남는다. 세 객차 파괴 → 기관차 방호 해제 → 마지막 추격/탈선 → 기관차 격파로 이어진다.
- 두 발진차는 독립적으로 동작한다. 예고 때 목표 좌표를 고정하고 두 협동 플레이어에게 공격을 나누며, 준비 중인 발진차를 파괴하면 그 발진만 취소된다. 보급차 파괴는 재장전을 지연한다.
- Kettering Bug는 고정 지점으로 직선 비행한다. 저프레임에서도 도착점을 정확히 통과 처리하며, 현대식 추적·선회·재조준을 하지 않는다. 발진 준비와 비행에 같은 원본 기체를 사용하고 발진 연기 시간도 정상적으로 종료된다. 기체를 격추하면 착탄 표시는 제거된다.
- 분리된 객차와 잔해는 세계 좌표와 관성을 유지한다. 앞쪽 차량이 잔해 위로 후진해 겹치지 않도록 제동 후 반대 방향으로 빠져나간다. 살아 있는 분리 객차의 기능은 계속 작동한다.

## 트레파스 바겐

- 차체 방향을 따라 전진·후진하며 끝 지점에서 먼저 제동한다. 한쪽 차륜과 조향륜 손실은 속도와 완만한 편향에 반영되고, 양쪽 차륜이 없어지면 위치·방향·차륜 회전이 정지한다.
- 기존 연결형 그림에서 주포 포신만 분리해 회전한다. 실제 조준 → 고정 목표 예고 → 그 포신 끝에서 발사 → 반동이 이어진다. 차축과 바퀴 가장자리는 유지하고 드럼 중앙의 판만 굴러간다.
- 이동 중에는 간격이 있는 집중 포격, 고정 포대에서는 포위 포격과 집중 포격을 번갈아 쓴다. 포탑 파괴는 아직 발사하지 않은 포격을 취소한다. 이미 발사된 포탄과 눈에 보이는 차체 기관총은 남는다.
- 부품 피해를 전체 게이지에도 한 번 반영한다. 두 부품 파괴 후 차체를 마무리할 수 있다. 파괴 영역은 기존 정렬된 잔해 아틀라스로 교체한다.
