- G.IK: 전방 중포가 1.25초 동안 방향을 고정하고 기수를 맞춘 다음 현재 포구에서 발사한다. 포구 파괴로 조준과 사격을 중단한다. 후방 사수는 후방 범위에서만 사격하며 연속 폭탄은 예고된 실제 투하 지점에서 떨어진다.
- Ca.4: 좌·중앙·우 세 폭격로 중 하나를 안전 통로로 남기고 매번 통로를 바꾼다. 예고 시점에 좌표를 고정해 카메라 이동으로 낙탄 지점이 바뀌지 않는다. 투하 전 폭탄창이 열리고, 파괴 시 동체 최대 체력의 16% 내부 피해와 함께 남은 폭격을 취소한다.
- 두 기체: 기존 정상 스프라이트와 표식을 유지한다. 엔진 파괴로 기동이 느려지고 좌우 기울기가 달라지며 동체 방호가 감소한다. 순간 재배치와 무적 재진입을 제거했다. 무장 파괴로 해당 총탄과 대기 중인 중포 발사가 중단된다.
- 그림 크기, 회전, 약점, 탄환의 이전 위치를 포함하는 충돌, 화면 밖 표시는 동일한 측정 좌표를 사용한다. 부위 피해는 한 번만 동체에 전달한다.

검증: 전체 회귀 67개 통과. 루프 최고 패턴 배율의 120초 전투에서 풀 초과 없음. 루트 JS 108개 문법 검사 통과. 저장소 기준 상대 참조 누락 없음. 기존 `boss-drachen-parts-v2.webp`는 원격 기준 트리에 존재하나 로컬 부분 체크아웃에 없어 전체 배포 검증 스크립트는 해당 1건으로 실패한다. `validate.log`에 원문을 보존했다.

전후 비교: 테스트 저장소의 실제 `drawStageBoss`를 native Canvas에서 실행했다. 두 기체 × 7상태 × PC/모바일 × 전/후 = 56화면. 이미지 로드 누락 없음. Canvas 변환 상태 보존 확인. 브라우저 플레이·입력·HUD·배포 확인은 포함하지 않는다. 폭탄과 사격 효과의 실제 host 연동은 별도 테스트에서 검증했다.
