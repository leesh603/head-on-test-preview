## 전투

슈바벤 보루는 7개 부위가 각자 공격/지원 기능을 가진다. 관측소는 중포의 위치를 확정하고, 표시된 빈 통로 옆으로 집중 포격한다. 관측소 파괴는 예약 포격을 취소하고 플레이어 좌표를 사용하지 않는 고정 구역 포격으로 전환한다. 탄약고 파괴는 단발성 내부 유폭, 중포 재장전 6.7초→10.8초, 포격 수 축소, AA/MG 간격 증가를 적용한다. 중포 3개 중 2개 또는 지원시설 2개 파괴가 지휘 코어를 연다. 남은 무장은 계속 살아 있다.

마크 I은 3개의 독립 본체이며 전체 HP는 host의 기존 스케일된 예산 1개를 보존한다. 포형 1대는 멈춰 좌표를 확정한 3연포격, 기관총형 2대는 서로 교대 표적으로 측면 화망을 만든다. 부위 피해는 본체에 0.8배를 한 번만 전달한다. 한 궤도 파괴는 17→6 속도로 감속하고, 두 궤도 파괴는 위치와 회전 고정이다. 무장 파괴는 해당 예고·잔여 사격을 취소한다. 회전 실루엣의 간격을 보정하고 정지한 전차와 잔해의 위치를 보존한다. 3대 격파 전에는 클리어되지 않는다.

## 렌더·검사

`comparison.html`에 개편 전/후 실제 모듈 렌더를 포함했다. 전체 node test 119개 통과(신규 솜 15개), 116개 root 모듈 syntax pass. `render.mjs`는 실제 host와 Canvas renderer를 호출하고 새 아틀라스 5개 모두 디코딩한다. 원본 alpha를 유지하고 normal frame의 alpha >=128 외곽을 크기 기준으로 사용한다. 전차 차체/궤도 간 분리 현상을 바로잡았으며, 상태별 alpha crop를 다시 중심 정렬하지 않는다. 손상/잔해 아틀라스와 등장 카드도 연결했다.

브라우저 입력과 UI/HUD 실제 플레이 검증은 하지 않았다. 로컬에서 최신 솜 텍스처가 누락되어 동일한 TerrainRenderer fallback 배경을 사용했다. local validate의 기존 바이너리 누락 6참조(4파일)는 `canonical-import-audit.json`에서 canonical main의 존재·SHA를 확인했다. 이 파일들을 수정하거나 교체하지 않는다.
