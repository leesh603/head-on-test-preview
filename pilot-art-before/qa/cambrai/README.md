## 실제 개선

**플리거주크:** 전체 편성이 화면 밖에서 기존 수직 철로를 따라 후진 진입한다. 두 발진차 교대 출격 → 손상/체력에 따른 시간차 교차 출격 → 살아남은 발진차의 최후 공습으로 이어진다. 준비 모션과 출격은 같은 객차/끝 좌표를 사용하며, 출격 예약·실제 출격 모두 화면 내 위치와 생존 여부를 확인한다. 보급차 파괴는 재출격을 늦추며 대공차/후미차 파괴는 해당 사격을 제거한다. 공습 후 3.2초 재장전 틈이 있다. 동시 출격 예약도 기존 5기 상한에 포함한다.

**트레파스바겐:** 원화의 전체 드럼 표면을 굴리고 림·축·끝 곡면·손상 원화를 보존한다. 좌우 회전량은 실제 이동 거리와 선회량에서 계산한다. 정지 선회와 화면 경계에서의 가짜 정지를 제거하고 무거운 전후진·넓은 선회로 압박한다. 한쪽 바퀴 손상은 속도/선회 편향, 조향 손상은 선회 능력 감소로 반영된다. 주포는 전방 기준 ±2.55rad 범위에서 각 착탄점으로 조준하고 실제 총구에서 순차 발사한다. 돌파 예고 → 가속·포격 → 제동·방향 전환·마지막 사격 → 3.2초 반격 틈. 두 바퀴 파괴 시 돌파를 취소하고 기존 고정 포격으로 전환한다.
