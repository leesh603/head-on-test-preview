기준 main: `7573bb0f2cdaa9b4d94847b8bc683a4e627181a8`.
작업 브랜치: `feat/adriatic-boss-tactics`. main 병합·배포 없음.
대상: SMS 슈투트가르트 / HMS 주비안.

## 슈투트가르트

| 구간 | 전술 |
| --- | --- |
| 등장 | 기존 수상기 모델 5기 선행 접근, 검은 매연 뒤로 실제 모함 모델 등장, 함포 사격 전 경고 |
| 100–80% | 좌우 함포 교차사격과 초기 편대 |
| 80–50% | 격납고 개방, 덮개 사출, 기존 함재기 연속 출격 및 대공 엄호 |
| 50–25% | 지그재그 항해와 선회, 편대의 공격 패스로 추격 방해 |
| 25% 이하 | 연막 이탈 항해, 경고 뒤 0.6초 간격의 세 차례 교차 출격과 대공 엄호 |

피해 제한도 80%/50%/25%로 맞춰 큰 피해가 전환 연출을 건너뛰지 않는다. 최후 경고 구간은 3.2초이며 이후 격파 가능하다. 부위는 이 구간에서도 파괴 가능하다.

격납시설 또는 연료 파괴는 추가 출격과 최후 재공격 지령을 중단한다. 살아 있는 기존 편대는 남는다. 대공포 파괴는 해당 사격을 제거하고, 보일러 파괴는 항해 속도와 선회 능력을 낮춘다. 기존 6기 상한을 유지하며 상한에 도달하면 살아 있는 편대를 두 기씩 재투입한다. 함재기를 순간 이동하거나 추가 생성하지 않는다.

## 주비안

| 구간 | 전술 |
| --- | --- |
| 등장 | 함포 섬광과 조준 경고, 각 플레이어 부근의 관측탄 물기둥, 선회 진입 |
| 100–50% | 실제 선체 방향에 따른 항해·선회와 좌우 교대 함포 사격 |
| 50% 또는 접합부 파괴 | 기존 접합부 경고·분리 기믹 유지, 파열음과 물보라 강화 |
| 분리 이후 | 선수의 전조 후 어뢰 돌입, 선미의 예측 박격포 지원 |
| 양쪽 생존·저체력 | 선수 돌입과 선미 교차 포격 협공 |
| 선수만 생존 | 회피 급선회 뒤 전조가 있는 어뢰 돌격 |
| 선미만 생존 | 회피 항해와 이동 경로를 가르는 예측 집중 포격 |

각 선체의 엔진 파괴는 이동·선회를 둔화시키며 선수 어뢰 또는 선미 최후 포격도 약화한다. 무장 파괴는 아직 발사하지 않은 공격과 이후 해당 무장 공격을 중단한다. 분리 시 기존 부위 피해와 총 HP를 보존한다.

박격포는 잠긴 경로의 한쪽에 배치해 반대편 회피 공간을 남긴다. 일반 무전조 억제 사격은 이 두 구축함 선체에서만 중단했다. 어뢰 경고선과 실제 선수 포구·발사 방향은 일치한다. 선체 분리 간격·회전·충돌·항적·침몰은 기존 시스템을 사용한다.
